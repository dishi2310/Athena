# Athena — Desktop Application

An independent desktop application project developed as part of the Desktop Application course at Newton School of Technology, ADY Patil University.

## 📌 About the Project

Athena is a desktop application designed to provide a user-friendly and interactive experience while addressing a practical user need. The project focuses on combining modern web technologies with desktop application development to build a functional, efficient, and maintainable application.

## 🎯 Objectives

- Develop a functional desktop application.
- Create a clean and intuitive user interface.
- Apply software development concepts to a real-world problem.
- Understand desktop application architecture.
- Build a maintainable and scalable application structure.

## ✨ Features

- Interactive and user-friendly interface.
- Desktop-based application experience.
- Organized and modular code structure.
- Responsive UI components.
- Input validation and error handling.
- Additional features based on the project's core functionality.

## 🛠️ Tech Stack

- **Electron** — Desktop application framework.
- **React** — User interface development.
- **Vite** — Frontend development and build tooling.
- **JavaScript** — Application logic.
- **HTML5 & CSS3** — Structure and styling.
- **Git & GitHub** — Version control.

## ⚙️ Installation and Setup

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/dishi2310/Athena.git
```

### 2. Navigate to the project directory

```bash
cd Athena
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the application

Use the development commands configured in `package.json` to start the frontend and Electron application:

```bash
# Start the Vite development server
npm run dev

# In a separate terminal, launch Electron
npm run start
```
